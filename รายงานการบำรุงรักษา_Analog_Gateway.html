ชุดอุปกรณ์ทวนสัญญาณผ่านคลื่นความถี่สูง (SHF) และชุดอุปกรณ์ Gateway สำหรับเชื่อมต่อ Analog
ชื่อสถานี : ที่ว่าการอำเภอย่านตาขาว
ศสส.ปค.เขต 9 (ส่วนแยกนครศรีธรรมราช)
สถานที่ : ตำบลย่านตาขาว อำเภอย่านตาขาว จังหวัดตรัง
รายการ ปกติ ไม่ปกติ หมายเหตุ
1. ชุดอุปกรณ์ทวนสัญญาณผ่านคลื่นความถี่สูง (SHF) พร้อมอุปกรณ์ประกอบ
- ตรวจสอบสภาพสายอากาศไมโครเวฟ (Microwave Antenna) ให้อยู่ในสภาพสมบูรณ์ พร้อมใช้งาน
- ตรวจสอบสภาพของอุปกรณ์ Power Injector ให้อยู่ในสภาพสมบูรณ์ พร้อมใช้งาน
- สถานะการทำงานของอุปกรณ์ Outdoor Antenna Unit (OAU) และ Outdoor Unit (ODU)
  ให้อยู่ในสถานะออนไลน์ (Online) และพร้อมใช้งาน
2. ชุดอุปกรณ์ Gateway สำหรับเชื่อมต่อ Analog
- สายอากาศแบบรอบทิศทาง (Omni Antenna) ให้อยู่ในสภาพสมบูรณ์ พร้อมใช้งาน
- ตรวจสอบสภาพของตู้และอุปกรณ์ภายในตู้ให้อยู่ในสภาพสมบูรณ์ พร้อมใช้งาน
- เครื่องวิทยุ HM788 VHF (ซ้าย) S/N :
   - ความถี่รับ–ส่ง (TRX Frequency) :
- เครื่องวิทยุ HM788 VHF (ขวา) S/N :
   - ความถี่รับ–ส่ง (TRX Frequency) :
- เครื่อง MPUC รุ่น DS-6610 S/N :
3. อุปกรณ์กระจายสัญญาณ (L3 Switch) แบบ 24 ช่อง
- ตรวจสอบสภาพภายนอกของอุปกรณ์ L3 Switch ให้อยู่ในสภาพสมบูรณ์ ไม่พบรอยชำรุด
- L3 Switch S5735-S24T4XE-V2 S/N :
- สถานะ LED หน้าอุปกรณ์     
- สถานะ   ,  
- สถานะ  
- สถานะการเชื่อมต่อ (Link) ระหว่าง L3 Switch กับ OAU (port 10GE1/0/1)
4. ระบบไฟฟ้าและระบบสายดิน (Electrical Power and Grounding System)
- ตรวจสอบอุปกรณ์ภายในตู้ Main AC ให้อยู่ในสภาพสมบูรณ์ พร้อมใช้งาน
- ตรวจสอบสายไฟและจุดต่อสายไฟ ไม่พบการชำรุด หลวม แตกหัก หรือฉนวนเสื่อมสภาพ
- แรงดันไฟฟ้าระหว่างสาย L – N : (ค่าแรงดันระหว่าง 180 - 240 โวลต์)
- แรงดันไฟฟ้าระหว่างสาย L – G : (ค่าแรงดันระหว่าง 180 - 240 โวลต์)
- แรงดันไฟฟ้าระหว่างสาย N – G : (ค่าแรงดันระหว่าง 0 - 2 โวลต์)
- ตรวจสอบระบบสายดิน (Grounding) และจุดต่อสายดินทุกจุด ให้อยู่ในสภาพสมบูรณ์ พร้อมใช้งาน
- ค่าความต้านทานสายดินระบบไฟฟ้า (AC Ground) (ค่าไม่เกิน 5 โอห์ม)
- ค่าความต้านทานสายดินระบบวิทยุ (RF Ground) (ค่าไม่เกิน 5 โอห์ม)
